## Symfony Import Export Bundle 2.0.1

This release improves package stability, documentation, onboarding, and the supported-version test matrix.

### Highlights

- Consistent canonical PSR-4 namespace
- Practical Company import and export example
- Dedicated installation, import, export, validation, customization, and upgrade guides
- Symfony 6.4, 7.x, and 8.x compatibility checks
- Bundle configuration and service-registration tests
- Read-only linting and stricter Composer/autoload checks in CI

### Installation

```bash
composer require hugoseigle/symfony-import-export-bundle:^2.0
```

### Upgrade

Review the [upgrade guide](https://github.com/HugoSEIGLE/symfony-import-export-bundle/blob/main/docs/upgrading.md) when migrating from version 1.x. The canonical namespace is `HugoSEIGLE\SymfonyImportExportBundle`.
