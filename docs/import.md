# Importing

An import is a preview of candidate entity changes. The bundle parses CSV/XLSX rows, uses Doctrine metadata for type conversion, submits each row to a Symfony form, and returns an `ImportResult`. It never calls `persist()`, `remove()`, or `flush()`.

## Configure an entity

```yaml
import_export:
    date_format: 'Y-m-d'
    bool_true: 'true'
    bool_false: 'false'
    validate_headers: true
    csv:
        delimiter: ','
        enclosure: '"'
        escape: '\'
        bom: false
    importers:
        App\Entity\Company:
            fields: [name, email, active]
            unique_fields: [email]
            allow_delete: false
```

Field order defines column order. With header validation enabled, input headers must be exactly the raw field list or the complete translated list generated by `ImporterTemplateInterface`. A UTF-8 BOM on the first CSV header is accepted.

Create a form type with every configured entity field. Symfony form constraints and transformers perform application validation and association lookup. Then call:

```php
$result = $importer->import($file, Company::class, CompanyImportType::class);
```

`getCreatedEntities()`, `getUpdatedEntities()`, and `getDeletedEntities()` return candidate changes. `getErrors()` returns `ImportError` values containing `row`, `field`, `message`, and `value`. Rows are processed independently.

## Operation permissions

The final named arguments restrict a particular call:

```php
$result = $importer->import(
    $file,
    Company::class,
    CompanyImportType::class,
    allowDelete: false,
    allowCreate: true,
    allowUpdate: true,
);
```

For deletion, `allow_delete: true` must also be configured. This appends a `deleted` column that the importer consumes; do not add that virtual field to the form.

## Supported conversions

- booleans using configured, case-insensitive tokens;
- `date`, `datetime`, `date_immutable`, and `datetime_immutable` using `date_format`;
- Doctrine-backed enums;
- to-one association values passed as a scalar to the form;
- to-many association values split on commas and passed as a list.

Only `.csv` and `.xlsx` filenames are accepted. Formula evaluation is not performed during data-only XLSX reads. See the runnable [Company example](../examples/README.md).
